# Rick & Morty Character Explorer 🛸

A modern, responsive web application built with React and Vite to search, explore, and bookmark characters and episodes from the Rick and Morty universe.

## ✨ Features

- 🔍 **Live Search**: Fast character searching powered by the [Rick and Morty API](https://rickandmortyapi.com/) with request cancellation support.
- 📱 **Fully Responsive**: Optimized UI for mobile, tablet, and desktop screens.
- ❤️ **Favorites System**: Save and manage favorite characters persisted in `localStorage`.
- 📺 **Episode Browser**: Explore episodes where each character appears with chronological and reverse sorting.
- 🎨 **Dark Theme**: Modern portal-inspired dark theme with smooth animations and status indicators.
- ♿ **Accessible**: Keyboard navigation support, ESC to close modals, and screen-reader friendly attributes.

## 🛠️ Tech Stack

- **React 18**
- **Vite**
- **Axios**
- **Heroicons**
- **React Hot Toast**
- **ESLint**

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Josheqani/rick-and-morty.git

# Navigate into the directory
cd rick-and-morty

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
# Lint the codebase
npm run lint

# Build for production
npm run build

# Preview production build locally
npm run preview
```
